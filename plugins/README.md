# Плагины Мисы

Брось файл в эту папку — и помощник подхватит его при запуске (или скажи
**«Миса, перезагрузи настройки»** без перезапуска). Так добавляют новые команды,
логику и знания ИИ, не трогая ядро.

## Три способа расширить

### 1. YAML-плагин (без программирования)
Файл `имя.yaml` — фраза превращается в цепочку действий:
```yaml
name: Мой плагин
prompt: "Доп. инструкция для ИИ (необязательно)"
commands:
  "фраза триггер":
    - say: "..."
    - app: "опера"
    - site: "ютуб"
```
Шаги: `say, app, site, search, key, type, wait, run/shell, scenario,
click, double_click, right_click, scroll`.

### 2. Python-плагин (полная свобода)
Файл `имя.py` с функцией `register(api)`:
```python
def register(api):
    api.add_command(["скажи привет"], steps=[{"say": "Привет!"}])
    api.add_command("моя команда", handler=my_func)   # my_func(ctx, text)
    api.add_prompt("Ты эксперт по Excel.")
```
`ctx.say(текст)` — сказать; `ctx.config` — настройки;
`from assistant import actions` — готовые действия.

### 3. Промпты (характер и знания ИИ)
Поле `prompt:` в YAML или `api.add_prompt(...)` в Python добавляет текст в
системную подсказку ИИ — так задают стиль, роль и экспертизу.

## Правила
- Файлы, начинающиеся с `_`, **не загружаются** (это шаблоны: `_template.py`,
  `_template.yaml` — копируй их и убирай `_`).
- Ошибка в одном плагине не роняет остальные — она покажется в журнале окна.
- Приоритет команд плагинов выше одиночных встроенных, но ниже сценариев.

Быстрая проверка: скажи **«Миса, плагин работает»** — ответит пример `example.yaml`.
