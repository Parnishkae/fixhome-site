# 🎙️ Голосовой помощник «Миса»

Офлайн голосовой помощник для **Windows**. Ждёт ключевое слово, слушает команду и
управляет компьютером: запускает программы, открывает сайты, ищет в интернете,
крутит громкость, делает скриншоты, блокирует ПК, управляет музыкой и окнами, а
также выполняет **сценарии** — цепочки действий по одной фразе.

Распознавание речи полностью **офлайн** (Vosk) — аудио никуда не отправляется.

---

## Возможности

| Скажи (после имени «Миса») | Что произойдёт |
|---|---|
| «открой браузер / блокнот / калькулятор» | запуск программы из `config.yaml` |
| «закрой хром» | закрытие программы |
| «открой ютуб», «зайди на гитхаб» | открытие сайта |
| «найди рецепт борща», «загугли погоду» | поиск в Google |
| «громче» / «тише» / «выключи звук» | громкость |
| «пауза», «следующий трек» | управление музыкой |
| «сделай скриншот» | снимок экрана в `Изображения\Screenshots` |
| «сверни всё», «закрой окно» | управление окнами |
| «заблокируй», «спящий режим» | блокировка / сон |
| «выключи компьютер» | выключение через 60 сек («отмена выключения» — прервать) |
| «который час», «какое сегодня число» | время и дата |
| «рабочее место» | **сценарий**: браузер + почта + Word |
| «выключись» | завершить работу помощника |

Все команды, программы, сайты и сценарии настраиваются в **`config.yaml`** —
код трогать не нужно.

## Установка (Windows)

1. Установи **Python 3.10+** с [python.org](https://python.org).
   На первом экране установщика отметь галочку **«Add Python to PATH»**.
2. Скачай этот проект (или `git clone`) и распакуй.
3. Дважды кликни **`install.bat`**.
   Он создаст окружение, поставит зависимости и скачает русскую модель Vosk (~45 МБ).
4. (по желанию) Для красивого нейросетевого голоса — **`install-voice.bat`**.
   Он поставит PyTorch (CPU, ~200 МБ) и скачает голос Silero (~60 МБ). Без него
   помощник использует системный голос Windows (или просто печатает ответы).

> Если антивирус ругается на библиотеку `keyboard` — это нормально (она перехватывает
> медиа-клавиши). Можно добавить папку проекта в исключения.

## Запуск

**Как приложение (окно + значок в трее, без консоли)** — дважды кликни
**`Misa.vbs`**. Появится окно статуса (😴 сплю / 🎤 слушаю / 🧠 думаю /
⚙️ выполняю) с журналом. Закрытие окна прячет её в трей; выход — из окна
или меню трея. Можно сделать ярлык `Misa.vbs` на рабочий стол.

**В консоли** (удобно для отладки) — `run.bat`, либо приложение с видимой
консолью — `run-app.bat`.

Дождись фразы «Я на связи», затем:

> **«Миса, открой браузер»** — можно одной фразой,
> либо **«Миса»** → (ответ «Слушаю») → **«сделай скриншот»**.

После имени помощник ~8 секунд слушает команды подряд, потом снова засыпает.

Полезное:
```bat
run.bat --list-mics        REM показать микрофоны (индекс -> speech.input_device)
run.bat --config my.yaml   REM свой конфиг
```

## Настройка `config.yaml`

**Своя программа:**
```yaml
apps:
  фотошоп: "C:\\Program Files\\Adobe\\Photoshop\\Photoshop.exe"
```

**Свой сайт:**
```yaml
sites:
  работа: "https://mycompany.slack.com"
```

**Свой сценарий (алгоритм действий):**
```yaml
scenarios:
  "утро":
    - say: "Доброе утро"
    - app: "браузер"
    - wait: 1
    - site: "почта"
    - site: "новости"
    - say: "Хорошего дня"
```
Типы шагов: `say`, `app`, `site`, `key` (напр. `win+d`), `type`, `wait`, `run`.

**Сменить имя помощника** — раздел `assistant.wake_words` (указывай несколько
похожих написаний, Vosk офлайн иногда слышит слово по-разному).

## 🧠 ИИ-мозг (понимает свободную речь и учится)

Если встроенной команды нет, фраза уходит в облачную нейросеть (Gemini или
Grok). Она понимает любые формулировки, ведёт диалог, сама решает, что сделать
на ПК, и может **запоминать новые команды** — выученная фраза дальше срабатывает
мгновенно, без обращения к ИИ (хранится в `data/learned.yaml`).

**Настройка (один раз):**
```bat
run.bat  REM должен быть установлен (venv). Затем:
.venv\Scripts\python.exe scripts\setup_ai.py
```
Скрипт спросит провайдера (`gemini` или `grok`) и API-ключ и сохранит их в
`secrets.yaml` — этот файл **не попадает в git** (он в `.gitignore`), ключ не
утечёт в репозиторий.

Примеры того, что теперь понимает:
- «сколько будет 15 процентов от 2000» — посчитает и ответит голосом
- «создай на рабочем столе папку Отчёты» — выполнит
- «запомни: когда я говорю „игровой режим“, закрой лишнее и открой стим» — выучит

Управление в `config.yaml`, секция `ai`:
- `enabled` — включить/выключить ИИ;
- `allow_shell` — разрешать ли ИИ выполнять команды системы (полный контроль);
- сменить провайдера/модель — перезапусти `setup_ai.py` или правь `secrets.yaml`.

> ИИ работает через интернет (запросы к Gemini/Grok). Распознавание речи и голос
> остаются как настроено; сам ИИ — облачный.

## Как это устроено

```
config.yaml            — все настройки, команды, сценарии
assistant/
  main.py              — главный цикл: имя -> команда -> действие
  recognizer.py        — микрофон + Vosk (офлайн распознавание)
  tts.py               — озвучка ответов (офлайн, SAPI5)
  dispatcher.py        — сопоставление текста с навыками
  actions.py           — низкоуровневые действия над ПК
  skills/              — навыки: программы, сайты, система, медиа, окна, сценарии
scripts/download_model.py — загрузчик модели Vosk
install.bat / run.bat  — установка и запуск в один клик
```

## Решение проблем

- **«Модель Vosk не найдена»** — запусти `install.bat` ещё раз или скачай модель
  вручную с [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models)
  (`vosk-model-small-ru-0.22`) и распакуй в папку `models/`.
- **Не слышит / не тот микрофон** — `run.bat --list-mics`, впиши индекс в
  `speech.input_device`.
- **Плохо распознаёт имя** — добавь варианты в `assistant.wake_words` или
  скачай большую модель `vosk-model-ru-0.42` (точнее, но ~1.5 ГБ).
- **Нет голоса ответов** — для нейросетевого голоса запусти `install-voice.bat`
  (движок `tts.engine: silero`). Для системного голоса поставь `tts.engine: sapi5`
  и русский голос SAPI5 в Windows. Помощник в любом случае печатает ответы в консоль.
- **Другой голос Silero** — поменяй `tts.speaker` в `config.yaml`
  (`aidar`, `baya`, `kseniya`, `xenia`, `eugene`).

## Приватность и безопасность

- Распознавание и синтез речи работают **локально**, без интернета.
- Помощник может запускать программы и выполнять команды на твоём ПК — это его суть.
  Держи `config.yaml` под контролем и не добавляй в сценарии команды из непроверенных
  источников.
